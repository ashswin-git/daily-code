# daily-code

100 days of small, self-contained Python projects.

Each day lives in its own folder under this monorepo. Original standalone repos may still exist for history; this repo is the consolidated home going forward.

## Days

| Day | Folder | Description |

| 23 | [day-23-ip-address-checker](./day-23-ip-address-checker/) | CLI IP address checker (IPv4/IPv6 type, subnet calculator, rDNS, free geo lookup) |
| 24 | [day-24-port-checker](./day-24-port-checker/) | CLI TCP port checker (lists, ranges, common preset, parallel scan, JSON) |

| 28 | [day-28-folder-size-calculator](./day-28-folder-size-calculator/) | Mini du: folder total, largest-first breakdown, biggest files and space by file type |

```bash
python3 main.py --help
```

Python 3.10+, standard library only unless a day says otherwise.
