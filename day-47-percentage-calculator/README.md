# Day 47: Percentage Calculator

A command-line calculator for everyday percentage problems.

**Difficulty:** Easy

## Features
- P% of a number
- What percent one number is of another
- Percentage change between two values
- Increase or decrease a value by a percentage

## Install
No dependencies; Python 3.8+ only.

## Usage
```bash
python main.py of 15 200
python main.py is 50 200
python main.py change 80 100
python main.py increase 100 10
python main.py decrease 100 10
```

## Example
```
$ python main.py of 15 200
15% of 200 = 30
```

## Requirements
Python 3.8+
