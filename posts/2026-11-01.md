# 2026-11-01 — Day 34: CSV to JSON Converter

Shipped `day-34-csv-to-json-converter`: a stdlib-only CLI that turns CSV into JSON as a list of objects, a list of arrays, an object keyed by any column, or JSON Lines. It auto-detects the delimiter, can convert numbers, booleans and nulls to real types, expands `a.b` headers into nested objects, and supports column picking, stdin and file output.
