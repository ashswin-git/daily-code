# 2026-11-07 — Day 38: HEX/RGB Color Converter

Shipped `day-38-hex-rgb-color-converter`: a stdlib-only CLI that converts colors between HEX, RGB and HSL. It accepts short hex, `rgb()` / `hsl()`, CSS names, shows an ANSI swatch, can check WCAG contrast between two colors, and supports random colors plus JSON output.
